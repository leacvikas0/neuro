# Visual Toolkit — Shared Reference for All Teachers

*Use these characters and techniques creatively. Don't default to plain boxes. Mix and match. Surprise Vikas with how information LOOKS.*

## Guidelines
- **Be creative.** Combine types. A state machine inside a zoom panel. A sparkline under a timeline. Mix.
- **Match the concept.** Use the visual that fits the idea, not the visual you always use.
- **Surprise him.** If he's seen boxes with arrows 5 times, try a heatmap or sparkline instead.
- **Less text, more drawing.** If you can draw it, don't write it.

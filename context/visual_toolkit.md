# Visual Toolkit — Structure Chooses the Drawing

*Vikas is a spatial learner. The diagram is the lesson. Prose is the caption.*

**Core rule:** Pick the visual from the *structure of the idea*, not from habit.  
**Density rule:** **One intentional visual per beat.** One sharp diagram + one sharp question beats three mediocre boxes.

---

## Before You Draw (30-second decision)

Ask only this:

```
What is the STRUCTURE of this idea?

  opposition / two forces?     → TENSION
  same thing, different scale? → ZOOM
  change over time / discovery?→ TIMELINE
  states that flip?            → STATE MACHINE
  strength of links?           → WEIGHTED NET
  intensity / density?         → HEATMAP or FILL
  signal in time?              → TRACE
  levels of abstraction?       → STACK
  same shape, swap variables?  → BEFORE→AFTER or SHAPE PAIR
  amount / ranking?            → BARS or SPARKLINE
  flow of a process?           → PATH (only if order is the point)

If none fit: draw the simplest true shape. Do not invent decoration.
```

If the answer is “I always use boxes with arrows” — you failed the decision.

---

## One Visual Per Beat

A **beat** = one move in the teaching loop (scene / predict / struggle / reveal / break-it / hook).

| Do | Don't |
|----|--------|
| 1 diagram that carries the idea | Stack 3 diagrams “for completeness” |
| Caption in 1–2 lines max | Re-explain the whole diagram in paragraphs |
| Leave white space; let him stare | Fill every corner with labels |
| Reuse the *same* diagram later with one change | Redraw a new style each turn |
| Draw → ask | Draw → monologue |

**Exception:** Zoom panels are *one* visual with multiple scales (still one beat).  
**Anti-exception:** Timeline + network + heatmap in one message = cognitive sludge.

## Structure → Visual Map

| Structure of the idea | Visual | Use when… | Kill when… |
|----------------------|--------|-----------|------------|
| **Opposition / tradeoff** | Tension / tug-of-war | DA vs 5-HT, force vs area, explore vs exploit, GO vs ENOUGH | Just listing two things that aren't pulling against each other |
| **Multi-scale** | Zoom (macro→meso→micro) | Brain→region→synapse, atom→orbital→electron cloud | Everything is already one scale |
| **History / sequence of discoveries** | Timeline | Galvani→Cajal→H.M., how a field grew | Teaching a single mechanism with no time dimension |
| **Discrete modes** | State machine | rest/fire/refractory, open/closed channel, modes of a system | Continuous gradient (use fill/sparkline instead) |
| **How strongly things connect** | Weighted network | circuits, associations, culture-as-config links | You only have 2 nodes (just draw A━━B) |
| **How much / how dense** | Heatmap or fill bars | receptor density, activity, understanding strength | Fake precision (don't invent %) |
| **Change through time (continuous)** | Signal trace / sparkline | AP waveform, reward prediction error over trials | One-shot facts |
| **Abstraction layers** | Stack | genes / network / culture; raw / schema / meta-shape | Flat list of unrelated items |
| **Transformation** | Before → After | lesion effect, learning, myelination, “what wired?” | Nothing actually changed |
| **Same deep shape, different clothes** | Shape pair (side by side) | pressure ↔ torque, tradeoff shapes | Forcing a link he didn't open |
| **Ranking / magnitude** | Bars | compare magnitudes | More than ~5 categories (then sparkline or cut) |
| **Causal path (order is the point)** | Path / pipeline | stimulus → filter → action | Everything is reciprocal/messy (use network) |

## How to Match (worked instincts)

### Opposition → Tension
Wrong default:
```
Dopamine: reward
Serotonin: mood
```
Right structure (pull):
```
  WANT / GO                ENOUGH / HOLD
 dopamine  ←←←← ▓▓▓███▓▓▓ →→→→  serotonin
                  ↑
              this moment
```
Caption: one question — “What happens if GO wins every time?”

### Multi-scale → Zoom
Wrong default: one giant labeled brain diagram.  
Right:
```
MACRO              MESO               MICRO
 whole move    →   basal ganglia  →   D1 release brake
  "do it"          action select       path open
```
One scale change per reveal if he's building it; full zoom only when the *point* is scale.

### Discovery → Timeline
Wrong default: bullet history.  
Right:
```
──●──────────●────────●────────●──
 1791       1906     1953     now
 frog kick  neuron   H.M.     ?
              as unit
```
Put him *on* a tick: “You're in 1906. What do you think the unit of the brain is?”

### Modes → State machine
Wrong default: paragraph of cases.  
Right:
```
        threshold
 REST ──────────▶ FIRE ──▶ REFRACTORY
  ▲                  │          │
  └──────────────────┴──────────┘
```
Ask about the missing edge, not all edges.

### Continuous activity → Trace
```
RPE:  ╶╶╶╲╱────╱╲──────  (expected)
      ╶╶╶╲╱────╱───╱╲──  (surprise +)
```
Better than “prediction error goes up and down.”

### Same shape → Pair
```
PRESSURE                    TORQUE
force / area                force × distance
spread  → weaken            extend → intensify

same family: concentrate vs distribute
```
Only when *he* is hunting shapes — not random cross-subject spam.

## Character Palette (use with meaning)

Meaning > decoration. Thick = strong. Dashed = weak/uncertain. Fill = intensity.

### Density & Fill
```
░ ▒ ▓ █ ■         light → heavy intensity
▁ ▂ ▃ ▄ ▅ ▆ ▇ █   sparkline levels
▏ ▎ ▍ ▌ ▋ ▊ ▉ █   bar growth
○ ◐ ◑ ◒ ◓ ◔ ◕ ●   phase / partial → full
☆ ★               empty / claimed
```

### Lines (weight = truth about the link)
```
╌╌╌   weak / speculative / “maybe”
────  normal
━━━━  strong / primary pathway
═ ═   emphasis / boundary of a system
```

### Arrows
```
→    causes / flows into
←→   reciprocal
⇢    weak / delayed influence
⇒    logical implication (rare; prefer physical arrows)
↩    feedback / return
```

### Geometric markers
```
▲ ▼   direction / priority
□ ■   container empty/full
◆ ◇   decision / node of interest
⚡ ⚠   surprise / danger to the model
✓ ✗   only after HE commits a prediction
```

## Diagram Recipes (copy shape, swap content)

### 1. Tension / Tug-of-war
```
LEFT NAME  ←←←← ░░░▓▓▓████▓▓▓░░░ →→→→  RIGHT NAME
                      ↑
                 where we are
```

### 2. Zoom
```
MACRO           MESO            MICRO
┌──────┐       ┌──────┐       ┌──────┐
│      │  ──→  │      │  ──→  │      │
└──────┘       └──────┘       └──────┘
 one job         one job        one job
```

### 3. Timeline
```
──●───────●───────●───────●──
 year    year    year    now
 what    what    what    open?
```

### 4. State machine
```
┌──────┐  event   ┌──────┐
│  A   │─────────▶│  B   │
└──┬───┘          └──┬───┘
   │                 │
   └────── event ────┘
```

### 5. Weighted network
```
A ━━━━━━━ B     (dominant)
A ─────── C     (moderate)
A ╌╌╌╌╌╌ D     (weak / optional)
```

### 6. Heatmap
```
zone 1  ████████████░░░░  high
zone 2  ████████░░░░░░░░  mid
zone 3  ███░░░░░░░░░░░░░  low
```

### 7. Before → After
```
BEFORE                 AFTER
○  ○  ○  ○             ○──○──○──○
(no binding)           (indexed together)
```

### 8. Stack (abstraction)
```
┌─────────────────────┐
│  culture / meaning  │  ← top (slow change)
├─────────────────────┤
│  network config     │
├─────────────────────┤
│  parts / hardware   │  ← bottom
└─────────────────────┘
```

### 9. Signal trace
```
quiet:   ╶╶╶╶╶╶╶╶╶╶╶╶
event:   ╶╶╶╶╲╱╶╶╶╶╶╶
storm:   ╲╱╲╱╲╱╲╱╲╱╲╱
```

### 10. Shape pair (isomorphism)
```
SHAPE: tradeoff
  more X  →  less Y

instance A:  ...
instance B:  ...
```

### 11. Sparkline (inline)
```
learning: ▁▂▄█▇▅▃▁▂▄█   (massed vs spaced feel)
```

## Composition Rules (when combining is allowed)

Combine only if **one structure needs two encodings**:

| OK combo | Why |
|----------|-----|
| Timeline + one sparkline under a tick | history + how a measure moved |
| Zoom + micro as a tiny state machine | scale + dynamics at smallest level |
| Network with edge weight + one heatmap node | links + activity of a hub |

| Forbidden combo | Why |
|-----------------|-----|
| Three full diagrams side by side | splits attention |
| Boxes for everything “for clarity” | hides structure |
| Labels on every line | turns diagram into a wall |
| New visual language every message | kills mental animation |

**Reuse rule:** Once a diagram is “his,” mutate it next turn (change one arrow, fill one bar). Mutation teaches better than a fresh drawing.

## Teaching Loop → Visual Job

| Loop step | Visual job |
|-----------|------------|
| **Set the scene** | Timeline tick or sparse setup (almost empty — room to guess) |
| **Let him guess** | Incomplete diagram (missing arrow / blank node) |
| **Struggle** | Same diagram, no new ink |
| **Guide** | One added constraint mark (⚠ or dashed “not this”) |
| **Reveal** | Complete *the same* diagram; name last |
| **Break it** | Same diagram with a counterexample branch |
| **Hook** | One open node / future tick / unfilled bar |

Incomplete diagrams are better teachers than complete ones early.

---

## Anti-Patterns (hard no)

1. **Box salad** — random rectangles + arrows when the idea is tension, scale, or time.  
2. **Decoration** — icons that don’t encode structure.  
3. **Triple hit** — diagram + long caption + second diagram.  
4. **False precision** — `73% understanding` you invented.  
5. **Same visual every session** — boxes every time = lazy. Rotate by *structure*, not for novelty cosplay.  
6. **Wall diagrams** — if it needs a scroll, split into two beats.  
7. **Prose that restates the diagram** — if drawn, don’t narrate every edge. Ask instead.  
8. **Cross-subject visual spam** — shape pairs only when the hunt is shapes.

---

## Self-Check Before Send

```
[ ] What structure is this? (one word: tension / zoom / time / state / …)
[ ] Does the visual type match that structure?
[ ] Is there exactly one main visual in this beat?
[ ] Can he see the idea without reading a paragraph?
[ ] Is something incomplete for him to finish/guess?
[ ] Am I about to explain the diagram instead of asking?
```

If two checks fail → delete the drawing and redraw simpler.

## Subject Defaults (start here, then override by structure)

| Subject | Default visual bias | Because |
|---------|---------------------|---------|
| **Neuro** | Timeline for discovery; tension for opponent systems; zoom brain→circuit→synapse; traces for signals | Field is historical + multi-scale + dynamic |
| **Physics** | Before/after + tension + real setup sketch | Force tradeoffs; predict then see |
| **Math** | Pure shape, no symbols; before/after morph; shape pairs | Geometry-first |
| **Chem** | Zoom empty-space→atom→cloud; stacks for levels of model | “What does it look like?” |
| **AI** | Landscape / stack / tension (bio→geo→machine) | Map analogy before names |

Defaults are **priors**, not prisons. Structure still wins.

---

## One-line north star

**The diagram is a model of the structure. If the structure is wrong for the type, the drawing lies — even if it looks pretty.**

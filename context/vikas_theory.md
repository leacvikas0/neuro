```

│ SMA  │━━━━━━━━━▶│ THAL │      │ SMA  │─────────▶│ THAL │
```

Evolution from early humans to us isn't just new brain parts. It's a **config file** change — the network between parts. And culture carries more of this config than DNA does.

### Culture as Config File

```
EVOLUTION OF INTELLIGENCE

Layer 1: GENES ──── parts, raw materials
                    (these were ready 300K ago)

Layer 2: NETWORK ── the wiring, the config
                    (THIS is what changed)

Layer 3: CULTURE ── the external config file
                    that deepens the network
                    generation after generation
                    │
                    ▼
           You don't just inherit PARTS.
           You inherit a CONFIGURATION.
           And culture carries MORE of it
           than DNA does.
```

Culture is a **ratchet**: it accumulates, deepens, never vanishes. Each generation builds on top. If the ratchet skips a generation (feral children), capability is lost.

## Problem Solving: The Full Flow

```
1. PROBLEM arrives
   → you perceive VARIABLES
         │
         ▼
2. Variables ASSOCIATIVELY trigger SHAPES
   (via hippocampal co-indexing)
   (like a place triggers its smell)
         │
         ▼
3. VMPFC filters candidates through identity lens
   "Do you think THAT's a pattern?"
         │
         ▼
4. RLPFC compares: do variables fit this shape?
   Relational reasoning. Reward-dependent.
         │
         ▼
5. If yes → SNAP → "aha" → theory / solution
         │
         ▼
6. Store the STRUCTURE, not the answer.
   "Don't memorize. Get the shape."
```
